# 星穹战机

一个零依赖、可直接在浏览器里运行的双人合作飞机大战网页小游戏。

## 启动方式

直接用浏览器打开 [index.html](./index.html) 就能玩。

如果你更习惯本地服务，也可以在这个目录起一个静态服务器后再访问。

## 操作说明

- `P1`：`WASD` 控制蓝翼号
- `P2`：方向键控制赤焰号
- `空格`：开始游戏 / 重新开始
- `P`：暂停 / 继续

## 玩法说明

- 两位玩家自动持续开火，共享总分与关卡阶段
- 每位玩家都有独立生命、护盾、当前武器和火力等级
- 任意一位玩家被击落后，如果还有生命，会短暂延迟后返场
- 两位玩家都彻底离场时，本局结束

## 武器类型

- `脉冲`：标准高频主炮
- `散射`：扇形压制弹幕
- `激光`：高穿透直射束
- `追踪弹`：会自动寻找最近敌机
- `电弧`：横向摆动的清场弹群

## 补给说明

- `F`：提升当前武器火力等级
- `W`：切换到新的武器类型
- `S`：获得护盾
- `H`：回复生命

## 敌人类型

- `侦察机`：速度快、血量低
- `突击机`：会瞄准玩家点射
- `截击机`：横向冲刺压迫走位
- `炮塔机`：悬停并发射扇形弹幕
- `轰炸机`：耐久高，会投下重型炸弹
- `王牌机`：高血量精英单位，发射多连发攻击
