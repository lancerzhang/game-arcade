# 星穹战机

一个零依赖、可直接在浏览器里运行的双人合作飞机大战网页小游戏。

## 启动方式

直接用浏览器打开 [index.html](./index.html) 就能玩。

如果你更习惯本地服务，也可以在这个目录起一个静态服务器后再访问。

开始界面可以切换 `单人模式` 或 `双人模式`。

## 操作说明

- `P1`：`WASD` 控制蓝翼号
- `P2`：方向键控制赤焰号
- `P1 大招`：`左 Shift`
- `P2 大招`：`右 Shift` 或 `Enter`
- 单人模式下：任意 `Shift` 都可以触发 P1 大招
- `空格`：开始游戏 / 重新开始
- `P`：暂停 / 继续

## 玩法说明

- 可选单人突围或双人合作，共享总分与章节推进
- 每位玩家都有独立生命、护盾、当前武器和火力等级
- 每位玩家都有独立大招充能，击落敌机和持续作战都会累积能量
- 大招未充满时按下 Shift，会有即时提示
- 任意一位玩家被击落后，如果还有生命，会短暂延迟后返场
- 两位玩家都彻底离场时，本局结束
- 战局会按波次推进，每个章节的末尾都会进入 Boss 战

## 武器类型

- `脉冲`：标准高频主炮
- `散射`：扇形压制弹幕
- `激光`：高穿透直射束
- `追踪弹`：会自动寻找最近敌机
- `电弧`：横向摆动的清场弹群

## 补给说明

- `F`：提升当前武器火力等级
- `W`：切换到新的武器类型
- `S`：获得护盾
- `H`：回复生命

## 大招说明

- `蓝翼号 - 星流风暴`：高频锁定打击，快速清理多目标并抹除部分弹幕
- `赤焰号 - 赤焰天降`：空袭轰炸，对聚集敌人造成范围爆发伤害

## 波次与 Boss

- 每个章节有 3 波常规敌军，节奏从试探、混编到重火力逐步加压
- 第 4 个遭遇为章节 Boss，会有独立血条和多阶段招式变化
- 击破 Boss 后进入下一章节，敌军强度和编队复杂度都会提高

## 敌人类型

- `侦察机`：速度快、血量低
- `突击机`：会瞄准玩家点射
- `截击机`：横向冲刺压迫走位
- `炮塔机`：悬停并发射扇形弹幕
- `轰炸机`：耐久高，会投下重型炸弹
- `王牌机`：高血量精英单位，发射多连发攻击
